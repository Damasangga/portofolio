# Portfolio – Damas Angga Pramudya

Static one-page portfolio (HTML + CSS, no build step).

## Files
- `index.html` – the page
- `cv.pdf` – CV linked from the page (remove it, and the "Download CV" button, if you prefer not to publish your phone number)

## Deploy free with GitHub Pages
1. Create a new **public** repository on GitHub, for example `portfolio`.
   (Name it `<username>.github.io` to get the shorter URL `https://<username>.github.io`.)
2. Click **Add file → Upload files**, drag in `index.html`, `cv.pdf` and `README.md`, then **Commit changes**.
3. Open **Settings → Pages**. Under **Build and deployment**, set Source to **Deploy from a branch**, choose branch `main` and folder `/ (root)`, then **Save**.
4. Wait 1–2 minutes. Your site is live at `https://<username>.github.io/portfolio/`.

## Alternatives
Cloudflare Pages or Netlify (drag-and-drop the folder) also host this for free.

## Edit
Open `index.html` in any text editor. Text lives in the HTML; colors are the variables at the top of the `<style>` block.
